# Descripción del Repositorio

## Para la sección "About" de GitHub:

**Descripción corta (ideal para About section):**
```
🔐 API REST empresarial para gestión segura de usuarios con Spring Boot 3, Java 17, JWT y MySQL. Demostración de arquitectura moderna y mejores prácticas de seguridad.
```

**Descripción extendida:**
```
Demostración completa de un sistema de autenticación y gestión de usuarios empresarial utilizando Spring Boot 3, Java 17, Spring Security con JWT, MySQL y Swagger. Implementa patrones arquitectónicos modernos, cifrado BCrypt, sistema de roles y documentación automática de API. Ideal para portfolios técnicos y como base para proyectos empresariales que requieren autenticación robusta.
```
